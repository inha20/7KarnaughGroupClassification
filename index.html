초록 / Abstract

본 논문은 4변수 카르노맵 위의 부울 함수 공간 F₄를 변수 순열군 S₄, 입력 반전군 Z₂⁴, 이 둘이 이루는 부호 순열군 B₄ = Z₂⁴ ⋊ S₄와 그 부분군인 카르노맵의 격자 대칭군 W의 작용으로 분류한다. 필요한 정의와 증명을 본문에 싣는 것을 목표로 하는 논문이며, 일부 수치(궤도 크기 분포, 그림 종류별 함수 개수)는 컴퓨터로 수행한 유한 계산이다. 카르노맵에 특화된 결과는 변수 배치 동치류와 그림 종류 수의 판정(정리 4, 5)이며, 3,984 · 402 · 30 · 32 · 7 같은 궤도 수는 대부분 문헌에 알려진 값의 재계산이다. 주요 결과: 변수 배치 동치류 $24 \to 3$, 대칭 부울 함수 $2^5 = 32$개, 아핀 함수 10궤도 · 단조 함수 30궤도 · 자기쌍대 함수 32궤도 · 전체 F₄ 3,984궤도 (S₄ 작용). S₄와 격자 평면 대칭 D₄grid(회전·반사 8개)가 생성하는 합성군 B₄(크기 384) 하에서는 전체 F₄ 402궤도 · 아핀 6궤도 · 자기쌍대 7궤도. 본문의 수치는 Burnside 보조정리의 계산과 저자가 작성한 Python 전수 열거의 출력을 서로 대조했다.

핵심 개념: 변수 배치 동치류 Hamming Layer S₄ 궤도 (Burnside) B₄ 합성군
🔑 핵심 정리 / Key Theorems
정리 1 — 변수 배치 동치류 (격자 대칭 W, 위수 128)
$|\mathcal{E}| = \dfrac{\binom{4}{2}}{2} = 3$
24개 배치 → 격자 대칭 W(위수 128)가 배치에 일으키는 변환(위수 8의 이면체군, 자유 작용) → 3개 동치류 (AB/CD, AC/BD, AD/BC). 토러스 이동 없이 격자 평면 대칭 D₄grid 8개만 쓰면 12개로 갈라진다. 그림의 행·열 구조를 보존하는 W 대신 B₄ 전체를 허용하면 모든 배치가 한 동치류가 되어 구분이 사라진다.
§4 — 완전 대칭 함수
$|\text{Sym}_4| = 2^5 = 32$
Hamming weight 5개 레이어 × 독립적 0/1 선택
§5 — S₄ 궤도 분류 (Burnside)
전체 F₄: 3,984궤도 · 아핀: 10 · 단조: 30 · 자기쌍대: 32
Fix 표 전부 수록, 단조 30궤도 완전 목록 포함, Python 전수 열거와 대조
§5.5 — 자기쌍대 ∩ 완전 대칭 = ∅
$D \cap \mathcal{S}_4 = \emptyset$
완전 대칭이면서 자기쌍대이려면 $v_{4-k} = \neg v_k$인데 $k = 2$에서 $v_2 = \neg v_2$가 되어 모순
정리 2·3 — 합성군 ⟨S₄, D₄grid⟩ = B₄
$G = \langle S_4, D_4^{\mathrm{grid}} \rangle = B_4 = \mathbb{Z}_2^4 \rtimes S_4$, $|G| = 384$ · F₄: 402궤도 · 아핀 6 · 자기쌍대 7
직접곱이 아님 (두 군은 가환하지 않고 |D₄grid ∩ S₄| = 2). 20개 켤레류 Burnside로 증명 + 전수 열거 검증
명제 2 — 패리티와 체커보드
Gray 축 순서에서 4변수 XOR의 그림은 체커보드, 이진 축 순서에서는 이중대각
Gray 인접 셀은 한 비트만 달라 해밍 무게의 홀짝이 반전됨. 대칭 함수의 그림은 24개 변수 배치에서 모두 같음(명제 1)
정리 4 — 카르노맵 그림의 대칭과 종류
시각 대칭 = $W$ 안정화군의 원소 · 그림 종류 수 = $B_4$-궤도 안의 $W$-궤도 수 (1, 2, 3)
함수 3,220 / 36,204 / 26,112개가 각각 1 / 2 / 3종의 그림을 가짐 (전수 열거와 일치)
정리 5 — 그림 종류 수의 판정
그림 종류 수 = 안정화군 $H_f$의 $S_3$ 상이 세 변수쌍 분할에 작용할 때의 궤도 수 (자명 → 3종, 위수 2 → 2종, 위수 6 → 1종)
$W \backslash B_4 / H_f$의 개수 = $H_f$의 $B_4/W$ 위 궤도 수. 402개 궤도 전부에서 열거와 일치
따름정리 6 — 위수 3인 상은 없다
안정화군의 $S_3$ 상은 위수 1, 2, 6 중 하나. 3-순환을 포함하면 상 = $S_3$ (그림 1종)
위수 3 원소는 부호 벡터 공액으로 순수 3-순환과 켤레이고, 세 좌표 위에서 $C_3$-궤도 = $S_3$-궤도(해밍 무게별)이므로 3-순환 불변이면 호환 불변
개수의 유도 — 포함·배제와 뫼비우스
그림 1/2/3종 함수: 3,220 / 36,204 / 26,112 · 단조 궤도 크기 1, 3, 4, 6, 12: 6, 2, 9, 6, 7개 · $\mathrm{Fix}_M((12)(34)) = 28$
군 폐포 위 포함·배제로 $N_6 = 3{,}220$, $N_{\ge 2} = 39{,}424$ ($S_4$ 부분군 30개 위 뫼비우스로 단조 안정화군 위수별 개수). 계산은 컴퓨터로 수행한 유한 계산(닫힌 식 아님)
참고 — 알려진 값과의 관계
3,984(A003180) · 402(A000616, Slepian 1953) · 단조 30, 210(A003182) · 자기쌍대 32(A057132), 7(A001531)은 문헌에 있는 값의 독립 재계산
$W$가 $B_4$의 지표 3인 부분군이라는 사실(정리 1)도 카르노맵 밖에서 알려져 있음(Lawrencenko 2013, van Leeuwen 1999). 카르노맵에 특화된 부분은 그림 종류 수의 판정(정리 4, 5)이며 선행 연구 조사는 제한적임
