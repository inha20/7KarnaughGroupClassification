세 클론의 Burnside 표

공간마다 켤레류별 Fix 값만 다르고, 계산 방식은 같다

공간C1 (1개)C2 (6개)C3 (3개)C4 (8개)C5 (6개)합 Σ |Ck|·Fix궤도 수
전체 F465,5364,0961,0242566495,6163,984
아핀 L321688424010
단조 M168502815872030
자기쌍대 D25664016076832

궤도 수 = (합) / 24 · 표의 값은 모두 verify_orbits.py, verify_tables.py로 열거와 대조

발표자 노트 · 슬라이드 21

3분세 공간 각각에 대해 켤레류 대표원의 Fix 값을 적은 표입니다. ‘합’은 원소 수 가중합 Σ|Ck|·Fix, 이를 24로 나누면 궤도 수입니다.

아핀: 32 + 6·16 + 3·8 + 8·8 + 6·4 = 240 → 10. 단조: 168 + 6·50 + 3·28 + 8·15 + 6·8 = 720 → 30. 자기쌍대: 256 + 6·64 + 3·0 + 8·16 + 6·0 = 768 → 32. (맨 위 줄은 전체 공간, 2부의 결과.)

2장의 질문의 답이 여기서 나옵니다: 10, 30, 32. 그런데 이 Fix 값들은 어떻게 구할까요? 공간마다 논증이 달라서, 이어지는 22장~31장에서 아핀 → 자기쌍대 → 단조 순서로 하나씩 보입니다.

눈여겨볼 점: 자기쌍대에서 C3와 C5의 Fix가 0입니다. 왜 0이 나오는지가 25장~26장의 주제입니다.

아핀 공간 L의 Fix

σ로 불변 ⇔ 같은 순환 안의 변수는 계수가 같다

C1 id(1)(2)(3)(4)m = 425 = 32
C2 (12)(12)(3)(4)m = 324 = 16
C3 (12)(34)(12)(34)m = 223 = 8
C4 (123)(123)(4)m = 223 = 8
C5 (1234)(1234)m = 122 = 4
|Fix(σ, L)| = 2m+1(m = 변수 순환의 개수)
32 + 6·16 + 3·8 + 8·8 + 6·4 = 240 → 240 / 24 = 10 궤도

발표자 노트 · 슬라이드 22

2분아핀 함수 f = c0⊕c1x1⊕…⊕c4x4에 변수 순열 σ를 적용하면 계수 벡터 (c1,…,c4)가 같은 방식으로 섞입니다. 따라서 σ로 불변이려면 σ의 같은 순환 안에 있는 변수들의 계수가 같아야 합니다.

변수 순환이 m개이면 자유롭게 고를 수 있는 것은 상수 c0 하나와 순환별 계수 하나씩, 모두 m+1개 → |Fix| = 2m+1. 켤레류별 m은 4, 3, 2, 2, 1이므로 32, 16, 8, 8, 4. 합 240, 240/24 = 10.

전체 공간의 2c(g)(입력점의 순환 수)와 달리 여기서는 ‘변수의 순환 수’ m이 쓰이는 점을 짚어 주세요.
