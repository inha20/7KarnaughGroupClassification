보수(¬)와 충돌하는 순환이 있으면 Fix = 0

예: x = (0, 1, 0, 1)

x = 0101σ = (12)(34)1010
  • σ(x) = 1010 = ¬x
  • 순환 {x, ¬x}가 보수에 닫혀 있다
  • σ로 불변이면 f(x) = f(¬x)
  • 그러나 자기쌍대는 f(¬x) = ¬f(x)
  • → 모순, 그래서 Fix = 0

S4-고정점 없음 (D에는 크기 1 궤도가 없다)

발표자 노트 · 슬라이드 25

3분자기쌍대 함수는 f(¬x) = ¬f(x)를 만족합니다. 변수 순열 σ는 보수 사상 x↦¬x와 가환하므로, 보수는 σ가 만드는 입력점 순환들을 서로 옮깁니다.

(i) 어떤 σ-순환이 보수에 대해 닫혀 있으면, σ로 불변인 f는 그 순환 위에서 상수여야 하는데, 순환 위의 점 x와 ¬x가 모두 있으므로 f(¬x)=¬f(x)와 모순 → Fix = 0. (ii) 그렇지 않으면 순환들이 보수 쌍으로 짝지어지고, 쌍마다 값을 하나 고르면 되므로 Fix = 2c(g)/2.

구체 예: x=(0,1,0,1)을 (12)(34)로 보내면 (1,0,1,0) = ¬x입니다. 곧 이 순환 {x, ¬x}가 보수에 닫혀 있어 C3에서 Fix=0. (1234)도 같은 점을 같은 점으로 보내므로 C5에서 Fix=0. C2, C4에서는 그런 순환이 없어 212/2=64, 28/2=16.

결과: 256 + 6·64 + 0 + 8·16 + 0 = 768 → 32궤도(크기 4인 궤도 16개, 크기 12인 궤도 16개), 고정점 없음. 이 ‘고정점 없음’은 완전 대칭 함수에서 v4−k = ¬vk가 k=2에서 모순이 된다는 것과 같은 이야기입니다(논문 5.5절).

자기쌍대 함수: 왜 어떤 순열에서는 Fix가 0일까?

자기쌍대 조건 f(¬x) = ¬f(x)과 순열 작용 σ(x) = ¬x의 정면 충돌

규칙 정의

1. 자기쌍대의 정의와 256개

  • 자기쌍대의 정의: 모든 입력 비트를 반전(¬)시키면, 함수 출력도 정확히 반전되어야 합니다: f(¬x) = ¬f(x).
  • 반대 입력은 반대 출력: f(0000) = 0 이면 반드시 f(1111) = 1 이어야 합니다.
  • 보수 쌍 8개: 16개 입력점은 {x, ¬x} 형태의 8개 보수 쌍으로 나뉘므로, 각 쌍마다 앞의 값을 정하면 뒤는 자동 결정되어 28 = 256개입니다.
충돌 현장

2. 치명적 충돌의 발견

  • 순열 σ = (12)(34) 살펴보기: 1번과 2번을 바꾸고, 동시에 3번과 4번을 맞바꾸는 순열입니다.
  • 입력점 x = 0101 대입: 1번과 2번을 바꾸면 10, 3번과 4번을 바꾸면 10 이 되어, 결과는 σ(x) = 1010 이 됩니다!
  • 치명적인 일치: σ(x) = ¬x: 순열을 단 한 번 적용했을 뿐인데, 원래 입력의 비트를 전부 뒤집은 보수(¬x)와 완벽히 같아집니다!
모순 증명

3. 피할 수 없는 수학적 모순

  • 조건 1 (순열 불변): f(x) = f(σ(x)) = f(¬x)
  • 조건 2 (자기쌍대 철칙): f(¬x) = ¬f(x)
  • 두 조건을 합치면: f(x) = ¬f(x) (0 = 1 이라는 불가능한 모순!)
  • 결론: Fix = 0: 이런 충돌 순열을 견뎌낼 수 있는 자기쌍대 함수는 수학적으로 0개입니다! 따라서 C3와 C5에서는 단 1개도 살아남지 못합니다.
