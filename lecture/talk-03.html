군과 작용: 변수를 바꾸면 함수가 옮겨진다

질문변수 이름을 섞는 24가지 조작은 함수를 어떻게 움직일까?

한 줄 답S4의 원소 g는 (g·f)(x) = f(g−1x)로 함수를 옮긴다. x1은 크기 4, x1⊕x2는 크기 6, 4변수 XOR는 크기 1인 궤도를 만든다.

수학에서 ‘군(Group)’과 ‘작용’이란?

변수 이름을 바꾸는 변환들의 대수적 모임과 함수 그래프 이동의 원리

정의

군(Group): 변환의 세계

  • 조작들의 집합: 수학에서 군(Group)은 어떤 대상에 가할 수 있는 ‘변환(조작)’들의 모임입니다.
  • 대칭군 S4의 원소 24개: 4개의 변수 이름 A, B, C, D를 뒤섞는 모든 순열의 개수는 4! = 24가지입니다.
  • 군의 필수 조건 3가지: ① 연속해서 섞어도 유효한 섞기, ② 아무것도 안 섞기(항등원), ③ 원래대로 되돌리기(역원)가 모두 가능합니다.
고교 연결

왜 역원 g−1이 붙을까?

  • 수식: (g·f)(x) = f(g−1x): 새 회로(g·f)에 입력 x를 넣었을 때 올바른 결과가 나오도록 배선을 거꾸로 되감는 수식입니다.
  • 회로 배선 맞바꾸기 비유: 1번과 2번 핀을 맞바꾼 새 회로에 (0,1)을 넣으면, 내부의 옛 기계 f는 1번 핀(1,0)으로 신호를 되감아(g−1) 받아야 정상 작동합니다!
  • 도형 평행이동과의 연결: 고1 때 y=f(x)를 오른쪽(+a)으로 밀면 식에 f(x - a)처럼 반대 부호가 붙던 것과 완전히 똑같은 ‘좌표 역추적’ 원리입니다.
의미

함수의 ‘작용(Action)’

  • 함수 공간 위를 이동: 순열 g를 가하면 함수 f가 새로운 식 g·f로 변신합니다.
  • 구조의 보존: 이름표는 바뀌었지만 참/거짓의 논리 구조 자체는 조금도 훼손되지 않고 보존됩니다.
  • 본질적 동일성: 따라서 f와 g·f는 겉모습만 다를 뿐 ‘동일한 종류의 부울 함수’로 간주할 수 있습니다.

변수를 바꾸면 함수가 옮겨진다

변수 순열군 S4 (위수 24)가 입력점과 함수에 작용한다

입력점에 작용:(πx)i = xπ(i)
함수에 작용:(g·f)(x) = f(g−1x)
f = x1
x1x2x3x4
궤도 크기 4
f = x1 ⊕ x2
x1⊕x2x1⊕x3x1⊕x4x2⊕x3x2⊕x4x3⊕x4
궤도 크기 6
f = x1⊕x2⊕x3⊕x4
x1⊕x2⊕x3⊕x4
궤도 크기 1 (고정점)

발표자 노트 · 슬라이드 8

2분S4의 원소 π는 입력 좌표를 섞습니다: (πx)ᵢ = xπ(i). 이것이 함수에 작용할 때는 (g·f)(x) = f(g−1x)로 정의합니다. 직관적으로는 ‘변수 이름을 바꿔 쓴 함수’입니다.

아래 세 줄로 궤도의 모양을 보여 줍니다. f=x1은 변수 이름만 바꾸면 x2, x3, x4가 되어 크기 4인 궤도를 만듭니다. f=x1⊕x2는 변수 쌍을 고르는 방법 C(4,2)=6가지이므로 크기 6. 4변수 XOR은 어떻게 이름을 바꿔도 같은 함수이므로 크기 1, 곧 S4의 고정점입니다.

참고: 이 정의는 합성 순서가 뒤집히는 오른쪽 작용이지만 궤도 수·고정점 수·안정화군은 왼쪽 작용으로 읽어도 달라지지 않습니다(논문 2.3절).
