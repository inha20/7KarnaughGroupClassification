궤도 · 안정화군 · 고정점

궤도의 크기는 24를 안정화군의 위수로 나눈 값

궤도
G·f = { g·f : g ∈ G }
f와 같은 모양의 함수 전체
안정화군
Stab(f) = { g : g·f = f }
f를 바꾸지 않는 변수 순열
궤도–안정화군 정리
|G·f| = |G| / |Stab(f)| = 24 / |Stab(f)|
크기는 24의 약수
고정점
G·f = {f} ⇔ Stab(f) = S4

발표자 노트 · 슬라이드 9

2분세 개념을 정의합니다. 궤도 G·f는 f에서 출발해 도달 가능한 함수들의 집합, 안정화군 Stab(f)는 f를 그대로 두는 원소들의 부분군입니다. 궤도–안정화군 정리에 의해 |궤도| = |G| / |Stab(f)| = 24/|Stab(f)|.

오른쪽 표는 그 예입니다. 상수 0은 모든 순열이 고정하므로 Stab = S4, 크기 1. f=x1은 x1을 고정하는 순열이 변수 2,3,4를 섞는 S3(위수 6)이므로 크기 24/6=4. f=x1⊕x2는 {x1,x2}와 {x3,x4}를 각각 보존하는 ⟨(12),(34)⟩ ≅ Z2×Z2(위수 4)이므로 크기 6.

크기 1인 궤도의 원소를 S4-고정점이라 부릅니다. 이 개념이 뒤에서 세 클론을 구분하는 단서가 됩니다(고정점 있음/없음).

‘궤도(Orbit)’란 무엇인가? — 목걸이와 부품 규격

변수 이름표를 바꿔서 서로 도달할 수 있는 함수들을 한 바구니에 담은 동치류

고교 수학

목걸이 순열의 직관

  • 고교 원순열 · 목걸이 순열: 빨강, 파랑, 노랑, 초록 구슬로 꿴 목걸이를 식탁 위에서 회전시켜도 새로운 목걸이가 아닙니다.
  • 회전으로 묶기: 회전해서 같아지는 4가지 배치를 ‘1개의 목걸이’로 묶어 세듯, 군론에서도 변환으로 같아지는 대상을 하나로 묶습니다.
  • 동치류(Equivalence Class): 전체 공간을 겹치지 않는 묶음들로 분할하는 것이 바로 동치류 분할입니다.
공학 관점

전자회로 칩의 관점

  • f1 = A ∧ B: 두 입력 A, B가 모두 참일 때만 1을 내는 AND 회로입니다.
  • f2 = C ∧ D: 두 입력 C, D가 모두 참일 때만 1을 내는 AND 회로입니다.
  • 수식은 다르지만 칩은 같다: 외부 핀 이름표만 A, B에서 C, D로 바뀌었을 뿐, 반도체 제조사 입장에서는 완전히 동일한 2입력 AND 표준 셀입니다!
결론

궤도(Orbit)의 정의

  • 수학적 정의: f의 궤도 G·f = { g·f : g ∈ S4 } 는 24개 순열을 적용해 나오는 모든 함수들의 모임입니다.
  • 거대한 압축의 기적: 수식 기준으로는 65,536개나 되는 방대한 함수들이, 궤도로 묶으면 정확히 3,984개의 궤도로 분류됩니다!
  • 핵심 연구 목표: 이 3,984개의 궤도 수를 하나하나 세지 않고 수학적으로 계산하는 것이 번사이드 보조정리의 힘입니다.
