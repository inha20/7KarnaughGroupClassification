대칭성이 높을수록 궤도는 작아진다!

궤도-안정화군 정리: |궤도의 크기| × |안정화군의 위수| = 24 (전체 순열 수)

기본 정리

대칭성과 보존 법칙

  • 안정화군 Stab(f)의 정의: 변수 순열 중 함수 f의 모양을 조금도 바꾸지 않는 순열들의 모임입니다.
  • 대칭성의 척도: 함수가 완벽한 대칭을 이룰수록 Stab(f)에 들어가는 순열의 개수가 많아집니다.
  • 보존 법칙: 어떤 함수든 [궤도 크기] × [안정화군 크기]의 곱은 항상 전체 군의 크기 24가 됩니다!
사례 비교

세 가지 극적인 예시

  • 완전 대칭: XOR (크기 1): A⊕B⊕C⊕D는 24가지 순열 어떤 것을 가해도 불변! |Stab| = 24이므로 궤도 크기는 24/24 = 1 (혼자만의 궤도).
  • 부분 대칭: f = A (크기 4): A는 그대로 두고 B, C, D를 섞는 3! = 6가지에 불변. |Stab| = 6이므로 궤도 크기는 24/6 = 4 ({A, B, C, D}).
  • 비대칭 함수 (크기 24): 대칭성이 전혀 없으면 |Stab| = 1. 24가지 순열마다 전부 다른 수식이 만들어져 궤도 크기가 최대(24)가 됩니다.
수학적 함의

궤도 크기의 제약

  • 24의 약수만 가능: 궤도의 크기는 24를 나눈 몫이므로 반드시 24의 약수 (1, 2, 3, 4, 6, 8, 12, 24) 중 하나여야 합니다.
  • 불가능한 궤도 크기: 크기가 5개나 7개인 궤도는 수학적으로 절대로 존재할 수 없습니다!
  • 공간의 분할: 65,536개의 전체 함수 공간은 이 8가지 가운데 실제로 나타나는 6가지(1, 3, 4, 6, 12, 24) 크기의 궤도 조각들로 채워집니다. 크기 2와 8은 가능하지만 나타나지 않습니다.

번사이드 보조정리

궤도의 수 = 군의 원소들이 고정하는 대상 수의 평균

|X / G| = (1/|G|) Σg∈G |Fix(g, X)|
Fix(g, X) = { x ∈ X : g·x = x }

부울 함수에서는

g로 불변인 함수 = g의 각 순환 위에서 값이 상수

|Fix(g, F4)| = 2c(g)

c(g): 입력점 16개 위에서 g가 만드는 순환의 개수

워밍업: 2변수 (S2, F2 = 16개)

항등: c = 4 → 24 = 16개 고정

(12): 00, 11은 고정, 01 ↔ 10 → c = 3 → 23 = 8개

(16 + 8) / 2 = 12 종류

발표자 노트 · 슬라이드 12

3분이 강의의 핵심 도구입니다. 유한군 G가 유한집합 X에 작용할 때 궤도 수 = (1/|G|) Σ |Fix(g,X)|. 읽는 법: 각 원소가 고정하는 대상의 수를 모두 더해 군의 크기로 나눈다, 곧 ‘고정점 수의 평균’.

부울 함수에서는 한 가지 사실이 계산을 단순하게 만듭니다. g로 불변인 함수는 g가 일으키는 입력점의 각 순환 위에서 값이 상수여야 하므로, |Fix(g, F4)| = 2c(g), 여기서 c(g)는 입력점 16개 위의 순환 개수입니다.

워밍업(오른쪽 카드): 2변수, S2. 항등은 24=16개를 고정, 두 변수를 맞바꾸는 (12)는 입력점 00,11을 고정하고 01↔10을 맞바꾸므로 순환이 3개 → 23=8개 고정. (16+8)/2 = 12. 직접 세어도 12임을 학생들과 확인해 보면 좋습니다.

참고: 이름은 Burnside(1897)의 교재에서 왔으나 Cauchy와 Frobenius가 먼저 알고 있었습니다(Neumann, 1979).
