순환 구조가 16개 입력점을 쪼개는 원리

왜 순열 g로 불변인 부울 함수의 개수는 2c(g)로 단숨에 계산될까?

예시 분석

구체적 예시: 순열 (12)

  • 순열 g = (12) (A ↔ B 맞교환): 변수 A와 B의 위치만 바꾸고, C와 D는 그대로 두는 가장 단순한 교환 조작입니다.
  • A = B인 입력점 (8개): 0000, 0001, 0010, 0011, 1100, 1101, 1110, 1111 은 A와 B가 같으므로 A↔B를 바꿔도 제자리! → 크기 1인 순환 8개.
  • A ≠ B인 입력점 (8개): 0100 ↔ 1000 처럼 둘씩 짝지어져 서로 위치가 맞바뀝니다! → 크기 2인 순환 4개.
핵심 원리

순환 안에서는 출력이 동일

  • 불변 함수의 절대 규칙: 함수 f가 (12)에 의해 변하지 않으려면, 서로 맞바뀌는 입력점들에서는 반드시 출력이 같아야 합니다!
  • f(0100) = f(1000): 0100에서 1을 출력한다면, 1000에서도 무조건 1을 출력해야만 변수 교환 후에도 동일한 함수가 됩니다.
  • 순환 단위의 운명 공동체: 즉, 1개의 순환 안에 묶인 점들은 전부 동시에 0이 되거나, 전부 동시에 1이 되어야 합니다.
계산 공식

Fix(g) = 2c(g) 계산

  • 총 순환 개수 c(g) = 12: 크기 1 순환 8개 + 크기 2 순환 4개 = 총 12개의 독립된 순환 묶음이 생깁니다.
  • 독립된 12번의 선택: 각 순환마다 독립적으로 0 또는 1을 자유롭게 지정할 수 있습니다 (2가지 선택).
  • 고정점 수 = 212 = 4,096: 따라서 (12)로 불변인 함수는 정확히 212 = 4,096개! 5개 켤레류 모두 이 방식으로 Fix를 암산하듯 구합니다.

= 95,616 / 24 = 3,984

문헌(OEIS A003180)의 값과 일치하는 독립 재계산

발표자 노트 · 슬라이드 16

3분이제 Burnside에 대입합니다. 각 켤레류의 기여는 (원소 수) × 2c(g): 1×216=65,536, 6×212=24,576, 3×210=3,072, 8×28=2,048, 6×26=384. 합은 95,616이고 24로 나누면 정확히 3,984입니다. 나누어떨어진다는 것 자체가 계산 검산입니다.

이 값은 새로운 결과가 아니라 문헌(OEIS A003180)에 알려진 값의 독립 재계산입니다. 또 저장소의 verify_orbits.py가 65,536개 함수를 직접 열거해 3,984를 얻고, Burnside 값과 일치함을 확인합니다(33장에서 다시 언급).
