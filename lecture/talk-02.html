4변수 부울 함수 공간

함수 하나는 16비트 하나이므로, 함수는 모두 216 = 65,536개

예: 4변수 XOR = 0110 1001 1001 0110 (칸 아래: 입력점 x1x2x3x4)

입력점과 함수

  • 입력점 x = (x1, x2, x3, x4) ∈ Z24: 모두 16개
  • 변수 이름: A = x1, B = x2, C = x3, D = x4
  • 함수 f : Z24 → Z2는 16개 값으로 결정된다
  • 함수 공간 F4의 크기 |F4| = 216 = 65,536
  • 표기: m(i, j, …)는 입력 i, j, …에서만 1인 함수 (민텀의 합)

발표자 노트 · 슬라이드 5

2분입력점 x=(x1,x2,x3,x4)는 {0,1}4의 16개 점입니다. 부울 함수는 이 16개 점 각각에 0 또는 1을 배정하는 것이므로 16비트 문자열 하나와 같습니다. 따라서 함수의 개수는 2의 16제곱, 65,536입니다.

왼쪽 격자는 입력점 16개를 2진수 순서로 늘어놓은 것이고, 칸 안의 큰 숫자가 함수값입니다. 예시는 4변수 XOR(홀수 개의 1이면 1)입니다: 0110 1001 1001 0110.

변수 이름은 A=x1, B=x2, C=x3, D=x4로 씁니다. 이 슬라이드의 격자는 단순한 진리표 배열일 뿐 카르노맵의 변수 배치 이야기가 아닙니다(그 부분은 오늘 범위 밖).

왜 4변수 부울 함수는 65,536개나 될까?

16개의 독립된 입력 상황마다 출력값 0 또는 1을 자유롭게 결정하는 경우의 수

1단계: 입력

16개의 입력 상황

  • 4개 스위치 (A, B, C, D): 각 변수는 참(1) 또는 거짓(0)의 2가지 상태를 가집니다.
  • 입력 상황의 수: 2 × 2 × 2 × 2 = 24 = 16가지의 서로 다른 입력 조합이 존재합니다.
  • 카르노맵 16칸: 이 16가지 상황이 바로 카르노맵 격자의 16개 칸에 1:1로 대응됩니다.
2단계: 결정

함수 1개 = 16비트 정수

  • 함수 f의 역할: 각 입력 상황에 대해 출력으로 0을 낼지, 1을 낼지 규칙을 정하는 것입니다.
  • 독립된 16번의 선택: 칸 0에서 2가지(0/1), 칸 1에서 2가지, …, 칸 15에서 2가지.
  • 총 경우의 수 216: 2 × 2 × … × 2 (16번) = 216 = 65,536가지 서로 다른 함수가 탄생합니다!
3단계: 핵심

거대한 공간과 군론의 목적

  • 전광판 비유: 16개 전구의 불을 켜거나 끄는 모든 패턴의 가짓수가 바로 65,536개입니다.
  • 연구의 출발 질문: 이 65,536개의 회로를 엔지니어가 전부 따로 설계해야 할까요?
  • 대칭성의 발견: 입력 핀 이름(A, B, C, D)만 바꿨을 때 같아지는 것을 묶으면 회로의 본질적 종류는 극적으로 줄어듭니다!
