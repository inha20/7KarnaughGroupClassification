아핀 함수의 고정점: 왜 2m+1일까?

순환으로 묶인 변수들은 반드시 동일한 계수(0 또는 1)를 가져야 한다

수식 구조

1. 아핀 함수의 수식

  • 아핀 함수의 일반형: f(x) = c0 ⊕ c1x1 ⊕ c2x2 ⊕ c3x3 ⊕ c4x4
  • 계수 5개의 선택: 상수항 c0과 변수 계수 c1~c4는 각각 0 또는 1입니다.
  • 총 크기 25 = 32개: 독립된 계수 5개를 결정하는 경우의 수가 25 = 32개이므로 아핀 함수는 전체 65,536개 중 단 32개뿐입니다.
핵심 메커니즘

2. 순환이 계수를 구속한다

  • 순열 σ = (123) 적용: 변수가 x1 → x2 → x3 → x1 로 순환하며 자리를 바꿉니다 (x4는 고정).
  • 불변 함수가 될 조건: 식을 변환해도 원래 식과 완벽히 같으려면, 맞바뀌는 변수들의 계수가 반드시 같아야 합니다: c1 = c2 = c3 !
  • 순환당 1개의 계수 선택권: 3개 변수가 1개의 순환으로 묶였기 때문에, 계수 선택권도 3개에서 단 1개(0 또는 1)로 묶입니다!
계산 결론

3. 공식 2m+1의 완성

  • m = 변수 순환의 개수: 예: σ = (123)(4) 이면 순환은 (123)과 (4)로 2개 (m=2)입니다.
  • 계수 결정 2m 가지: m개의 변수 순환마다 계수(0 또는 1)를 결정하므로 2m 가지입니다.
  • 상수항 c0의 2가지 선택: 상수항 c0은 변수 순열에 전혀 영향을 받지 않으므로 항상 2가지!
  • 공식: |Fix(σ, L)| = 2m+1: m=2이면 23 = 8개! 번사이드 공식에 대입하면 (32 + 6·16 + 3·8 + 8·8 + 6·4)/24 = 240/24 = 10개 궤도가 도출됩니다.

아핀 공간의 10개 궤도

계수 벡터의 해밍 무게 w (0~4)와 상수 c0 (0, 1)로 분류된다: 5 × 2 = 10

발표자 노트 · 슬라이드 24

2분10개 궤도는 (w, c0)로 완전히 정해집니다. w는 계수 벡터 (c1,…,c4)에서 1의 개수(0~4), c0는 상수항(0 또는 1)입니다. 5×2 = 10.

크기는 24/|Stab|: w=0과 w=4는 안정화군이 S4이므로 크기 1(고정점 4개: 0, 1, XOR, XNOR). w=1과 w=3은 S3(위수 6) → 크기 4. w=2는 Z2×Z2(위수 4) → 크기 6. 합 1+1+4+4+6+6+4+4+1+1 = 32.

여기서 아핀 공간의 고정점이 정확히 4개(O1, O2, O9, O10)라는 점이 자기쌍대(0개), 단조(6개)와 대비됩니다(32장).
