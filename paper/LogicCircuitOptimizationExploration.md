# 군론적 동치류 기반 논리 회로 최적화 가능성 탐색

**English Title:** Exploring Logic-Circuit Optimization Through Group-Theoretic Equivalence Classes  
**Document Type:** Exploratory Research Note  
**Status:** Hypothesis and experimental design; no hardware improvement has been demonstrated  
**Related Work:** [Group-Theoretic Classification of 4-Variable Boolean Function Spaces on Karnaugh Maps](KarnaughGroupClassification.md)

---

## 1. 목적과 범위

기존 연구는 4변수 부울 함수 전체 공간
\[
\mathcal F_4=\{f:\{0,1\}^4\to\{0,1\}\},\qquad |\mathcal F_4|=2^{16}=65,536
\]
에 입력 변수의 순열과 입력 반전을 포함하는 signed-permutation group \(B_4\)의 작용을 고려하고, 그 작용 아래 402개의 궤도(동치류)를 얻었다.

이 노트는 이 수학적 분류가 논리 회로의 합성·구현 자원 최적화에 활용될 수 있는지 탐색한다. 기존 논문의 분류 결과를 실제 회로 면적·전력·성능 개선으로 해석하지 않는다. 그러한 공학적 효과는 별도의 구현과 비교 실험으로 검증해야 한다.

## 2. 핵심 연구 질문

**4변수 부울 함수의 \(B_4\)-동치류 분류를 이용해 회로 구현을 재사용하거나 최적화할 수 있는가?**

구체적으로 다음 질문을 다룬다.

1. 같은 \(B_4\)-궤도에 속하는 함수들의 최적 회로는 공통된 구조 또는 변환 가능한 구조를 갖는가?
2. 각 궤도의 대표 함수에 대해 회로를 합성하고, 입력 순열·입력 반전으로 다른 함수의 구현을 얻는 방식이 유효한가?
3. 변환·제어 회로의 비용을 포함해도 게이트 수, 셀 면적, 전력 또는 지연 시간에서 이득이 남는가?
4. 이 접근은 기존 논리 합성 도구가 수행하는 최적화와 비교해 추가적인 이점을 제공하는가?

## 3. 수학적 출발점과 해석상 주의

기존 연구에서 확인한 핵심 수치는 다음과 같다.

- 4변수 부울 함수: 65,536개
- \(B_4\)-궤도: 402개
- 각 궤도는 입력 변수의 순열 및 입력 반전으로 서로 연결되는 함수들의 집합

따라서 각 궤도에서 대표 함수 하나를 선택해 함수들을 **분류·기술**하는 것은 가능하다. 그러나 다음 명제들은 서로 다르다.

- 함수 공간을 402개 동치류로 분류할 수 있다.
- 대표 함수의 회로를 변환해 동치류의 다른 함수를 구현할 수 있다.
- 여러 함수를 하나의 공유 가능한 회로 네트워크로 구현할 수 있다.
- 전체 회로 면적 또는 전력 소모가 감소한다.

첫 번째는 기존 수학적 결과다. 두 번째는 입력 변환의 정의와 구현을 통해 구성할 수 있는 가능성이다. 세 번째와 네 번째는 회로 아키텍처 및 실험으로 검증해야 할 공학적 주장이다.

특히
\[
\frac{65,536}{402}\approx 162.03
\]
은 함수 수와 궤도 수의 비율일 뿐이다. 궤도 크기는 동일하지 않으며, 이 값은 회로 면적·게이트 수·집적도 절감률을 뜻하지 않는다. **402분의 1 또는 402배의 하드웨어 개선을 주장하지 않는다.**

## 4. 비교해야 할 구현 시나리오

실험에서는 무엇을 구현하는지 먼저 명확히 구분해야 한다.

### 4.1 단일 함수의 독립 구현

하나의 4변수 함수를 대상으로 일반적인 논리 합성 결과와 궤도 대표 함수 기반 구현 결과를 비교한다. 이 경우 대표 함수 회로에 입력 변환을 적용하는 오버헤드가 포함된다.

### 4.2 한 번에 하나의 함수를 선택하는 재구성 가능 구현

회로 하나가 설정값 또는 제어 신호에 따라 65,536개 함수 중 하나를 선택해 구현하는 아키텍처를 고려한다. 대표 회로 저장, 함수 선택, 입력 재배열·반전, 설정 메모리 및 멀티플렉싱 비용을 모두 포함해야 한다.

### 4.3 여러 함수를 동시에 구현하는 다중 출력 회로

여러 함수를 동시에 계산해야 하는 경우에는 공통 부분식 공유와 다중 출력 논리 합성이 중요해진다. 단일 함수의 동치류 대표 회로를 재사용하는 전략이 다중 출력 공유에 유리한지는 별도로 검증해야 한다.

위 세 시나리오는 자원 모델이 다르므로 하나의 결과로 혼합하지 않는다.

## 5. 초기 실험 설계

### 5.1 기준선 구축

동일한 합성 도구, 버전, 라이브러리, 최적화 옵션 및 타이밍 제약을 사용해 비교 가능한 기준선을 만든다.

- 65,536개 함수 각각을 독립적으로 합성한 결과
- 기존 도구가 지원하는 기본 논리 최적화 결과
- 가능하다면 일반적인 LUT 기반 구현 결과

모든 함수에 대한 전체 합성이 부담스러우면 대표 함수 및 궤도별 표본으로 예비 실험을 진행하되, 표본 선정 기준을 기록한다.

### 5.2 동치류 대표 회로 생성

각 궤도에서 대표 함수 하나를 정하고, 해당 함수의 논리식과 진리표를 기준으로 Verilog 또는 동등한 중간 표현을 생성한다.

### 5.3 입력 변환 구현

함수의 군 작용에 대응하는 입력 순열과 입력 반전을 회로 수준에서 구현한다. 구현 방식은 다음을 구분해 평가한다.

- 외부 배선 재배치로 가능한 변환
- NOT 게이트 등 추가 논리가 필요한 변환
- 설정 신호, 멀티플렉서 또는 제어 로직이 필요한 변환

변환이 단순한 핀 재배치인지 실제 셀·배선 자원을 소비하는지에 따라 결과가 달라질 수 있으므로 비용 모델을 명시한다.

### 5.4 기능적 동등성 검증

각 변환 구현이 목표 함수와 동일한 진리표를 산출하는지 전수 검증한다. 4변수 함수의 경우 입력 조합은 16개이므로 전수 비교가 가능하다.

### 5.5 합성 및 측정

Yosys 등 재현 가능한 논리 합성 도구를 이용해 다음을 측정한다.

| 지표 | 의미 |
|---|---|
| 논리 게이트 수 | 선택한 기술 매핑 기준의 논리 자원 수 |
| 셀 면적 | 특정 표준 셀 라이브러리 기준의 합산 면적 |
| 지연 시간 | 설정한 입력·출력 및 타이밍 제약에서의 경로 지연 |
| 전력 | 지원되는 전력 추정 모델과 입력 활동률에 따른 추정치 |
| 변환 오버헤드 | 입력 변환·제어·멀티플렉싱에 필요한 추가 자원 |

FPGA LUT 수와 ASIC 표준 셀 면적은 서로 다른 구현 지표이므로 직접 같은 값처럼 비교하지 않는다. 실제 전력·면적 결과를 주장하려면 대상 기술 라이브러리, 제약, 추정 방법을 함께 기록한다.

## 6. 비교 실험의 공정성

비교군과 제안 방식은 가능한 한 동일한 조건을 사용해야 한다.

- 동일한 합성 도구 및 버전
- 동일한 기술 라이브러리와 매핑 설정
- 동일한 타이밍 제약
- 동일한 최적화 수준
- 변환 및 제어 논리를 포함하는 동일한 비용 범위
- 반복 실행 및 원자료 보존

특히 기준선 합성 도구가 이미 입력 대칭성이나 논리적 동등성을 활용하는지 확인해야 한다. 제안 방식이 기존 도구의 내부 최적화와 중복된다면 추가 이득이 없을 수 있다.

## 7. 예상 결과와 반증 가능성

이 연구는 성능 향상을 전제하지 않는다. 다음 결과 모두 연구적으로 의미가 있다.

| 관찰 결과 | 가능한 해석 |
|---|---|
| 면적·게이트 수 감소 | 동치류 기반 재사용이 특정 조건에서 자원 절감에 기여할 가능성 |
| 일부 지표만 개선 | 면적·전력·지연 사이의 상충관계 |
| 기존 합성 결과와 차이 없음 | 기존 도구가 동등한 최적화를 이미 수행할 가능성 |
| 오히려 자원 증가 | 변환·제어·배선 오버헤드가 재사용 이득을 상쇄할 가능성 |

측정값이 확보된 이후에만 개선 비율을 계산한다. 예를 들어 면적 감소율은 동일한 비교 조건에서
\[
\text{Area Reduction (\%)}=
\frac{A_{\text{baseline}}-A_{\text{proposed}}}
{A_{\text{baseline}}}\times100
\]
으로 정의할 수 있다. 이 값은 실제 측정 결과가 있을 때만 보고한다.

## 8. 후속 확장

4변수 사례에서 유효성이 확인되는 경우에 한해 다음을 검토한다.

1. 더 많은 입력 변수를 갖는 부울 함수 공간으로의 일반화
2. 다중 출력 함수에서의 공통 부분 회로 공유
3. FPGA LUT 매핑 및 ASIC 표준 셀 매핑 비교
4. 군론적 정규형 또는 대표 함수 탐색을 논리 합성 전처리로 사용하는 방법
5. 기존 합성 알고리즘과 결합했을 때의 효과

4변수 사례의 결과만으로 현대 모바일 SoC의 면적, 전력 또는 성능 향상을 주장하지 않는다. 실제 칩 수준의 효과를 논하려면 더 큰 논리 블록, 메모리·배선·클록·물리 설계의 영향까지 평가해야 한다.

## 9. 현재 결론

기존 카르노맵 연구의 402개 궤도 분류는 논리 회로 최적화 가능성을 탐색할 수 있는 수학적 출발점이다. 그러나 동치류의 개수는 하드웨어 자원 절감률이 아니다.

후속 연구의 핵심은 **동치류 대표 함수와 입력 변환을 이용한 구현이, 변환 비용을 포함하고 기존 논리 합성 기준선과 비교했을 때 실제로 더 효율적인가**를 검증하는 것이다.

현재 이 문서는 탐색적 가설과 실험 설계를 기록한다. 회로 면적·전력·지연 시간의 개선은 아직 측정되거나 입증되지 않았다.
